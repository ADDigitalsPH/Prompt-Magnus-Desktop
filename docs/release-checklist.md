# Release Checklist

Use this checklist before publishing a Windows release.

- [ ] Confirm app builds locally.
- [ ] Confirm Windows installer is generated.
- [ ] Confirm app name is Prompt Magnus Desktop.
- [ ] Confirm version number is correct in `package.json`, `src-tauri/tauri.conf.json`, and `src-tauri/Cargo.toml`.
- [ ] Confirm README is updated.
- [ ] Confirm privacy policy is accurate.
- [ ] Confirm license is included.
- [ ] Confirm GitHub release notes are prepared.
- [ ] Confirm unsigned artifact is uploaded.
- [ ] Confirm SignPath signing request is submitted.
- [ ] Confirm signed artifact is uploaded to release.
- [ ] Confirm SHA256 checksum is generated.
- [ ] Confirm clean install works.
- [ ] Confirm close-to-tray behavior works.
- [ ] Confirm `Ctrl + Space` launcher works.
- [ ] Confirm clipboard restoration works.
