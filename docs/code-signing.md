# Code Signing Policy

Prompt Magnus Desktop plans to use SignPath Foundation for free open-source code signing if the project is approved.

Free code signing through SignPath Foundation is intended only for open-source projects. Prompt Magnus Desktop must remain publicly available under an open-source license for this route.

## Signing Provider

The intended signing provider is SignPath.io through SignPath Foundation.

Depending on the SignPath Foundation process, the final Windows publisher shown by the operating system may appear as SignPath Foundation.

## What Gets Signed

Signing is intended only for official release artifacts built from the public repository.

Signed artifacts may include:

- Windows `.exe` installer files.
- Windows `.msi` installer files.
- Other installer or bundle artifacts generated by Tauri.

The exact signed file set depends on the final SignPath artifact configuration.

## Source And Build Requirements

Signed Windows artifacts must be built from the public source repository through the official GitHub Actions release workflow.

The private signing key is not stored in this repository. Signing credentials must not be committed to source control.

The GitHub Actions workflow should upload unsigned build artifacts first, then submit those artifacts to SignPath for signing.

## Official Releases Only

Code signing is intended for official releases only. Local development builds, pull request builds, and experimental artifacts should not be submitted for signing.

## Release Metadata

Release artifacts should include version metadata, product name, and publisher details where possible.

Expected product name:

```text
Prompt Magnus Desktop
```

Release versions should match the application version in:

- `package.json`
- `src-tauri/tauri.conf.json`
- `src-tauri/Cargo.toml`

## Checksums

Release checksums should be published when possible. SHA256 is preferred.

Unsigned and signed artifacts should be clearly distinguished in release notes.

## SignPath Configuration Placeholders

The GitHub Actions workflow contains placeholders for:

- `SIGNPATH_API_TOKEN` from GitHub Secrets.
- `SIGNPATH_ORGANIZATION_ID`.
- `SIGNPATH_PROJECT_SLUG`.
- `SIGNPATH_SIGNING_POLICY_SLUG`.

Do not hardcode secrets in the repository.

## Policy Notice

Free code signing is expected to be provided by SignPath.io with a certificate by SignPath Foundation if the project is approved.
